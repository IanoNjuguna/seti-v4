# Technique Catalog

Specific visual moves organized by what they achieve. Use these deliberately, not decoratively.

## Create hierarchy

### Scale contrast
Make the most important element significantly larger than everything else. A 3:1 or greater ratio between headline and body creates instant focus.

### Weight contrast
Pair one bold element with lighter supporting text. Avoid making everything medium weight.

### Color isolation
Use the accent color on only one or two elements per view. Where color appears, attention follows.

### Spatial grouping
Put related elements close together and separate groups with more whitespace. Proximity implies relationship.

### Numbering and labels
Use small uppercase labels ("01 — Overview") to structure long artifacts. They create rhythm and wayfinding.

## Create calm

### Generous margins
Default to 20–24% whitespace around content blocks. Crowded layouts feel anxious.

### Limited palette
Restrict the working palette to 3–4 colors. Each additional color increases cognitive load.

### Flat surfaces
Use solid backgrounds with thin borders instead of heavy shadows. Surfaces should feel stable.

### Single typeface
Commit to one font family. Variation comes from weight and size, not from mixing moods.

## Create energy

### Asymmetric composition
Place the focal point off-center. Use the rule of thirds or intentional negative space on one side.

### Bold accent block
Use one strong color field behind a key message. The block should be large enough to feel decisive.

### Diagonal tension
Introduce a subtle diagonal through image crops, slanted containers, or angled divider lines.

### Scale jump
Combine a very large element with very small supporting text. The contrast creates momentum.

## Create trust

### Generous line height on body
Use 1.5–1.6 line height for reading text. Dense text feels rushed.

### Tabular numbers for data
Align numbers by their decimal point. Format currency consistently.

### Clear borders and dividers
Use thin, consistent lines to separate information. They feel precise and honest.

### Restrained motion
If animating, use short durations (150–250ms) and ease-out curves. Avoid bounces, elastic effects, or auto-play carousels.

## Create sophistication

### Tight tracking on headlines
Use slightly negative letter-spacing on large type (-0.02em to -0.03em) for a refined, editorial feel.

### Microcopy as punctuation
Short captions, labels, and parentheticals can add personality without adding noise.

### Asymmetric inner padding
Inside cards, use different top/bottom and left/right padding to create visual interest while maintaining alignment.

### Material contrast
Pair one matte surface with one subtle gloss or texture. Do not overuse either.

## Avoid common mistakes

- **Center-align overdose**: Center only statements that need emphasis. Left-align reading text.
- **Border overload**: Use one border treatment per artifact. Do not mix hairlines, heavy lines, and dashed lines.
- **Shadow soup**: One soft shadow is enough. Multiple layered shadows look dated.
- **Gradient crutch**: Use gradients only when they add depth or motion, not to make something "premium."
- **Icon noise**: Every icon should earn its place. Decorative icons dilute meaning.
