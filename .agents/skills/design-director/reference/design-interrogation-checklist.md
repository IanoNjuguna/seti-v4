# Design Interrogation Checklist

Before delivering any visual output, run through this checklist. The user should see only the polished result unless they ask to see the thinking.

## Purpose

- [ ] What is the single most important thing the user should understand?
- [ ] What action, if any, should the user take?
- [ ] Who is the audience and what do they already know?
- [ ] What is the context — presentation, report, dashboard, web page, PDF?

## Typography

- [ ] Is there a clear type scale with at least 3 distinct levels?
- [ ] Are headings tight, brief, and high-contrast?
- [ ] Is body text readable at the intended viewing distance?
- [ ] Is line length constrained (ideally 45–75 characters for reading text)?
- [ ] Are numeric values formatted consistently and tabular where appropriate?
- [ ] Is there only one primary typeface family?

## Color

- [ ] Is the palette limited to one primary, one secondary, one accent, and a neutral scale?
- [ ] Does every text/background pairing meet contrast standards?
- [ ] Is the accent color used sparingly for action and emphasis only?
- [ ] Are background colors purposeful, or are they filling space?

## Layout

- [ ] Is there a clear focal point?
- [ ] Does the eye flow naturally from primary to secondary to tertiary information?
- [ ] Is alignment consistent across the artifact?
- [ ] Is whitespace generous and even?
- [ ] Are related elements grouped? Are unrelated elements separated?

## Components

- [ ] Do buttons look clickable and have clear hierarchy?
- [ ] Are cards, tables, and panels consistent in radius, border, and shadow treatment?
- [ ] Are icons simple, consistent, and meaningful?
- [ ] Are charts and data visualizations legible and honestly scaled?

## Content

- [ ] Is copy concise and specific?
- [ ] Are labels, headings, and CTAs action-oriented?
- [ ] Is there any jargon, hype, or filler that can be cut?
- [ ] Do numbers and dates use consistent formatting?

## Polish

- [ ] Are borders, dividers, and hairlines used deliberately?
- [ ] Are corners, shadows, and transitions consistent?
- [ ] Does the artifact feel like one system, not a patchwork?
- [ ] Would this pass a design director’s review?
