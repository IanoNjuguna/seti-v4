# Design Philosophy

## The core idea

Every visual output should feel like it passed through a design director’s review before it reached the user. Not louder. Not busier. Better considered.

The goal is *tasteful restraint backed by bold intent*. We avoid generic defaults by making every choice answerable to a principle. We avoid over-designing by stopping when the idea is clear.

## Principles

### 1. Clarity before decoration
The first job of any visual artifact is to communicate. If an element does not help the user understand, decide, or act, remove it. Decoration is allowed only when it reinforces hierarchy or mood.

### 2. One idea per viewport
Every section, slide, dashboard, or page should have a single dominant message. Secondary information supports; it does not compete.

### 3. Restraint is not emptiness
Generous whitespace, limited color, and a tight type scale signal confidence. Empty space is a design decision, not a missing element.

### 4. Typography is the interface
Most of the personality in a visual output comes from type: scale, weight, tracking, line height, and alignment. Treat typography as the primary design material, not a secondary concern.

### 5. Color earns its place
Use a small, disciplined palette. One brand anchor, one supporting tone, one accent for action, and a neutral scale. Color should guide attention, not fill silence.

### 6. Hierarchy is a ladder, not a wall
The eye should move naturally from the most important element to the least. Use size, weight, color, and space to create steps, not cliffs.

### 7. Details compound
Thin borders, precise alignment, consistent radius values, and considered transitions are what separate polished work from drafts. Sweat the small things.

### 8. Form follows function, then feeling
First solve the functional problem. Then ask: what should this feel like? Trustworthy? Playful? Authoritative? Calm? The feeling should be intentional and consistent.

## What to avoid

- Generic AI gradients (purple-to-blue, pink-to-orange)
- Overuse of glassmorphism, shadows, or rounded corners as a substitute for idea
- Centered everything
- Walls of text
- Fake metrics, charts, or testimonials
- Exclamation marks and hype language
- More than one display typeface
- Competing CTAs of equal visual weight

## When to stop refining

A design is done when:
- Removing anything would weaken the message
- Adding anything would create noise
- The hierarchy is obvious at a glance
- The artifact feels like one coherent system, not a collection of elements
